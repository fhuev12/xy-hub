# XY 脚本中心 v28（加密版）

Roblox 自绘界面脚本中心，28 个标签页，液态玻璃皮肤，内置 82 个功能按钮。

## 直接使用

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/fhuev12/xy-hub/main/loader.lua"))()
```

或者用更快的 CDN 镜像：

```lua
loadstring(game:HttpGet("https://cdn.jsdelivr.net/gh/fhuev12/xy-hub@main/loader.lua"))()
```

## 说明

- 源码以加密形式托管，`loader.lua` 只负责拉取并解密执行。
- 执行器需要支持 `loadstring`（绝大多数支持）。
- 界面里可自行调节：5 套风格、强调色、玻璃通透度、模糊强度。
- 加新脚本：游戏内「我的脚本」页可直接粘贴运行；长期保留请写进文件里的 `XY_Addons` 表。
